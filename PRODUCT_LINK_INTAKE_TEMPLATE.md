# Product Link Intake Template

Use this template when Chrissy supplies an official material or fixture link.

## Before saving anything

1. Confirm the client job folder.
2. Open the official product page.
3. Find the official product image rather than using a screenshot or guessed crop.
4. Check whether the page shows more than one color, size, surface, or matching piece.
5. Record the exact item number when the collection contains similar colors or shapes.
6. Decide whether each image shows one tile, several tiles, a full mosaic sheet, or an installed room.

## Working swatch

- Save the official product image directly inside the confirmed job's `swatches` folder.
- This is the working reference used for visualizations.
- Do not place it in `finalized-swatches` unless Chrissy later chooses it for that retained group.
- Use lowercase words joined by hyphens.
- Put the imperial size in a new filename when the size is known.
- Do not move or rename an older job file merely to update its measurement style without Chrissy's approval.
- When a pattern repeat is important, also save the maker's installed-room image or pattern diagram when available.

## Product-details file

Create a plain-language file beside the swatch using this form:

### Product

- Maker:
- Collection:
- Color or finish:
- Working swatch:
- Official product page:
- Official image represented:
- Exact item number:
- Image shows: one tile | several tiles | one full sheet | installed room
- Date checked:

### Appearance

Describe the color, movement, pattern, contrast, finish, and any important variation that should be preserved in a visualization.

### Listed sizes and properties

Show imperial measurements first.

| Imperial size | Surface | Edge | Thickness |
|---|---|---|---|
|  |  |  |  |

- Use the maker's listed imperial size when available.
- If the maker gives metric only, convert it and label a rounded result as approximate.
- Keep the original metric value in a source-notes section when needed for accuracy.
- For mosaics, record both the individual piece size and the full sheet size.
- Count how many pieces run across and how many rows run through the complete sheet when the flat maker image makes this clear.
- Record which full-sheet side will run across the named room surface and which side will run front to back. Turning a rectangular sheet changes the repeat count.
- For multi-tile patterns, record how many separate tiles create one complete repeat.

### Matching pieces

List mosaics, trims, borders, steps, or other matching pieces that could matter to the visualization.

### Visualizer use

- State which image is the color and surface reference.
- State whether the flat picture is one tile, several tiles, or one complete sheet.
- State the expected number of tiles or sheets across a known room surface when that room is already known.
- State that Chrissy must choose the size, surface, pattern, direction, grout, starting point, and covered surface.
- Record anything that cannot be drawn to scale from the product page alone.

### Source notes

Keep the official image address, original maker measurements, and any caution needed to trace the information later.

## Check before finishing

- The swatch opens and shows the correct color.
- The item number matches the exact color, shape, size, and finish Chrissy selected.
- A mosaic's piece size and full sheet size are not confused.
- The exact full-sheet image, its direction, and its decimal repeat count control the first scale check.
- A multi-tile or full-sheet picture is not treated as one individual tile.
- The details file names the correct maker, collection, and color.
- Imperial measurements appear first.
- Rounded conversions are marked approximate.
- The job index and handoff list the new files.
- The swatch is not presented as a different product merely because an identical retained copy also exists.
