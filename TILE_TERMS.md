# Tile and Material Terms

This is the Visualizer workspace's shared, plain-language tile dictionary. Every job agent should use these meanings when talking with Chrissy and when writing image instructions.

This file is a living guide. Each future Zoe cycle must read it and add or correct terms supported by Chrissy's work. If a term can mean more than one thing, the agent must say so and ask a short question before making an image.

The pictures produced by the visualizer are design aids. Product instructions, the tile installer, and current trade standards control the real installation.

Last updated: 2026-09-24

## The terms Chrissy asked about

| Term | Plain-language meaning |
|---|---|
| **Tile setting** | A broad phrase. It can mean the act of installing tile, or it can mean the chosen layout. For an image, the agent should confirm the size, pattern, direction, joint width, starting point, and covered surface. |
| **Staggered** | Each row starts in a different place, so the end joints do not line up. This word is incomplete by itself. The amount of shift should be stated, such as one-half, one-third, one-quarter, or random. |
| **Stack setting / stack bond / straight stack** | The horizontal and vertical joints line up to form a clean grid. These names are commonly used for the same basic layout. |
| **Vertical setting** | The long side of a rectangular tile points up and down. This describes direction only. The agent must still ask whether the joints are stacked or staggered. |
| **Vertical stack** | Rectangular tiles stand upright, and both the horizontal and vertical joints line up. |
| **Vertical running bond** | Rectangular tiles stand upright, but each column or row is shifted so the end joints are staggered. |
| **Soldier course** | One row or band of rectangular units standing upright, like soldiers. It is often used at an edge, over an opening, or as a decorative band. The name comes from masonry work and is also used informally in tile work. |

## Layout, direction, and pattern terms

| Term | Plain-language meaning |
|---|---|
| **Layout** | The full plan for where tiles start, how they repeat, where joints land, and where cuts appear. |
| **Pattern** | The repeated arrangement made by the tiles. |
| **Orientation** | Which way a rectangular or directional tile faces. |
| **Horizontal / landscape** | The tile's long side runs left to right on a wall, or follows the named left-to-right direction on a floor. |
| **Vertical / portrait** | The tile's long side runs up and down on a wall. On a floor, the exact travel direction must be named because “vertical” depends on the drawing or camera view. |
| **Straight lay / straight set / grid** | Tiles follow straight rows and columns. With one rectangular size, this normally means stack bond. |
| **Stack bond horizontal** | Rectangular tiles lie horizontally and all joints line up. |
| **Stack bond vertical** | Rectangular tiles stand vertically and all joints line up. Also called vertical stack. |
| **Running bond / brick joint** | Each row is shifted from the row beside it, like common brickwork. The amount of shift should be stated. |
| **Half offset / 50% offset** | Each row moves by one-half of a tile, so an end joint lands at the center of the tile beside it. |
| **One-third offset / 33% offset** | Each row moves by one-third of a tile. This is often used with long tile to reduce visible height differences caused by bowed tile. Follow the product maker's instructions. |
| **Quarter offset / 25% offset** | Each row moves by one-quarter of a tile. |
| **Random offset / random stagger** | Row starts change by planned, unequal amounts so the end joints do not form a repeating stair-step. “Random” still needs rules, such as minimum spacing between nearby end joints. |
| **Stair-step** | The end joints move by the same amount in each new row, creating a repeated diagonal line. |
| **Horizontal running bond** | Rectangular tiles lie horizontally and the rows are offset. |
| **Vertical running bond** | Rectangular tiles stand vertically and the rows or columns are offset. |
| **Soldier course** | A single upright row or band of rectangular units. It is not enough to describe an entire wall unless the whole wall is intended to use that upright arrangement. |
| **Stretcher course** | A horizontal row showing the long face of rectangular units. The name comes from masonry and may be used for brick-shaped tile. |
| **Header course** | A row showing the short end or short face of units. This is mainly a masonry term; in a tile picture, the agent should ask what face and direction Chrissy expects. |
| **Course** | One continuous row of tile or masonry units. |
| **Diagonal lay / diamond lay** | Square tile is turned, commonly 45 degrees, so it reads as diamonds instead of a straight grid. |
| **Herringbone** | Rectangular tiles meet at right angles to make repeating zigzags. A classic version points the zigzag along a 45-degree line. |
| **Double herringbone** | Pairs of rectangular tiles replace each single tile in a herringbone pattern, making a wider zigzag. |
| **Chevron** | Tiles with angled ends meet tip to tip to form continuous V shapes. Unlike herringbone, the ends are cut at an angle rather than meeting a long side at a right angle. |
| **Basketweave** | Small groups of rectangular tiles alternate direction to look woven. Some versions include a small square between the groups. |
| **Checkerboard** | Equal square tiles alternate between two colors, like a checkerboard. |
| **Pinwheel / hopscotch** | A small square tile sits near a corner of a larger square tile, and the group repeats with a turning motion. |
| **Windmill** | Rectangular tiles surround a small center square, creating a turning windmill shape. |
| **Corridor pattern** | Long rectangles form repeating lanes, often with smaller pieces or shifted rows between them. The exact manufacturer diagram should be used because versions differ. |
| **Modular pattern** | Two or more tile sizes repeat together as one planned unit. The exact sizes and percentages must be given. |
| **Versailles / French pattern** | A named modular layout using several square and rectangular stone or stone-look sizes. The supplied pattern diagram controls the repeat. |
| **Parquet pattern** | Small rectangles are grouped and turned in alternating directions to resemble wood parquet. |
| **Quarter-turn** | Each tile or group turns 90 degrees from the one beside it. This matters most when the face has a clear grain or direction. |
| **Picket** | Long six-sided tile shaped somewhat like a fence picket. It can be set upright, sideways, or in other maker-approved patterns. |
| **Hexagon** | Six-sided tile. Its direction should be stated as point-up or flat-top when that difference matters. |
| **Penny round** | Small round mosaics, usually supplied on sheets. |
| **Scallop / fan / fish-scale** | A curved, overlapping-looking shape. These names are sometimes used differently by different sellers, so the product picture should control. |
| **Arabesque / lantern** | A curving decorative shape with pointed ends. Exact outlines vary by maker. |
| **Mosaic** | Small tile pieces, often supplied together on a mesh, paper, or dot-mounted sheet. |
| **Mosaic piece size** | The size of one small tile inside a mosaic sheet. It is different from the size of the whole sheet. |
| **Mosaic sheet size** | The outside measurement of one complete assembled sheet, such as 11 x 12 1/2 inches. This full size controls the first picture-scale check. Keep the decimal sheet count so partial sheets are not lost. |
| **Sheet repeat** | The exact arrangement of pieces inside one full mosaic sheet. Repeat the whole sheet without rearranging or simplifying its pieces. |
| **Sheet direction** | Which measured side of a rectangular sheet runs across the surface and which runs front to back. Turning the sheet changes how many repeats fit. |
| **Full-sheet-first scale check** | Scale the complete maker sheet across the known surface first. Then use the number of small pieces inside each sheet as a second check. This prevents an assumed piece size from changing the maker's real repeat. |
| **Visible piece count** | The approximate number of small mosaic pieces that should appear across or through a known surface after the full-sheet count is set. It is a review check, not the starting measurement. |
| **Insert / dot** | A small contrasting piece placed at planned points inside a mosaic, such as a pale sage square inside a white basketweave. Its size and spacing must follow the maker's flat image. |

## Placement and design terms

| Term | Plain-language meaning |
|---|---|
| **Field tile** | The main tile covering most of a wall or floor. |
| **Accent tile** | A different tile used in a smaller area for emphasis. |
| **Feature wall / accent wall** | One wall selected as the main visual focus. “This wall only” should be treated as a strict surface limit. |
| **Border** | A strip of tile that frames or separates areas. |
| **Listello** | A narrow decorative border, most often used on a wall. |
| **Wainscot** | Wall finish that stops at a chosen height instead of going to the ceiling. The stopping height must be stated. |
| **Tile rug / inset** | A framed pattern placed inside a larger field, often on a floor. |
| **Niche** | A recessed shelf or opening in a wall, common in showers. Each inside face and edge may need its own tile direction. |
| **Return** | The short surface that turns around an edge, such as the side of a wall or doorway. |
| **Wrap / folded corner** | The layout or vein continues around a corner so the two faces look connected. |
| **Bookmatch** | Two neighboring pieces are opened like a book so their veins mirror each other. Often used with stone or large printed panels. |
| **Vein match** | Pieces are selected and turned so the visible vein appears to continue from one piece to the next. |
| **Grain / vein direction** | The direction followed by wood grain, stone veins, stripes, or another visible line in the material. |
| **Directional tile** | Tile whose picture, grain, texture, or shape has a clear facing direction. Some products have arrows on the back to guide placement. |
| **Full tile** | An uncut tile. |
| **Cut tile** | A tile trimmed to fit an edge, corner, fixture, or opening. |
| **Balanced cuts** | Edge cuts planned to look similar or visually even on opposite sides. |
| **Center line** | A reference line through the middle of a room, wall, fixture, or focal point. |
| **Control line / layout line** | A straight reference line used to keep rows and joints in the planned place. |
| **Datum line** | A fixed level or reference line from which heights and positions are measured. |
| **Starting point** | The exact place where the layout begins. It affects every visible joint and cut. |
| **Focal point** | The place the eye should notice first, such as a vanity, window, range, tub, or fireplace. Layout is often centered or balanced around it. |
| **Centered layout** | A layout arranged around a center line or focal point. It may center either a tile or a grout joint. |
| **Dry layout** | Tiles are placed without mortar first to check pattern, joint width, color mix, and cuts. |
| **Mockup** | A small sample installation or picture used for approval before doing the whole area. |
| **Module** | One complete group of tiles and joints that repeats. |
| **Pattern repeat** | The distance or tile group after which a pattern starts again. |
| **Joint alignment** | Whether grout lines continue across nearby walls, floors, corners, or other surfaces. |

## Size and proportion terms

| Term | Plain-language meaning |
|---|---|
| **Nominal size** | The size used as the product name, such as 12 × 24. It may not be the tile's exact measured size. |
| **Actual size** | The tile's real measured face size. Use this plus the grout joint when tile counts or joint positions matter. |
| **Aspect ratio** | The relationship between length and width. A 3 × 12 tile has a 4-to-1 shape and must look four times longer than it is tall. |
| **Caliber / calibrated size** | A size group used because fired tiles can vary slightly. Boxes used together should follow the maker's matching guidance. |
| **Rectified tile** | Tile whose edges were mechanically finished after firing for a more exact face size. |
| **Pressed edge / cushioned edge** | A factory-formed edge that may be slightly rounded rather than sharply cut. |
| **Large-format tile** | A broad trade description for larger tile. The exact standard or product instructions should be checked because the cutoff can depend on the use. |
| **Plank tile** | Long, narrow tile, often made to resemble wood boards. |
| **Sheet-mounted mosaic** | Small pieces held together on a sheet for installation. The sheet joints should not show more than the joints within each sheet. |
| **Multi-tile reference image** | One picture that shows several separate tiles together. Visible grout lines reveal the separate tiles. The whole picture must not be treated as one tile. |
| **Grout joint** | The planned space between tiles that is filled with grout. |
| **Joint width** | The measured width of the grout space. It changes the visible scale and the number of courses that fit. |

## Installation and quality terms that affect the picture

| Term | Plain-language meaning |
|---|---|
| **Substrate** | The surface under the tile, such as prepared concrete, wall board, or a tile backer panel. |
| **Backer board** | A panel used as a firm surface behind tile. |
| **Mortar / setting mortar** | The material that bonds tile to the prepared surface. “Thin-set” is a common informal name for a type of tile-setting mortar. |
| **Back-troweling / back-buttering** | Spreading mortar on the back of a tile before placing it. Current trade teaching may prefer “back-troweling,” while “back-buttering” is still widely understood. |
| **Notched trowel** | A hand tool with shaped teeth that spreads mortar in even ridges. |
| **Coverage** | How much of the tile back is supported by mortar after it is pressed into place. |
| **Waterproofing membrane** | A layer behind or below tile that helps stop water from reaching the structure. Tile and grout alone are not the waterproofing system. |
| **Crack-isolation membrane** | A layer intended to reduce the chance that certain cracks below will pass through to the tile. |
| **Grout** | The material that fills the planned joints between tiles. |
| **Grout color** | The color of the filled joints. Matching color makes the tile field quieter; contrasting color makes the pattern stronger. |
| **Movement joint / soft joint** | A flexible joint that allows small movement instead of being filled solid with grout or mortar. Its location should not be hidden in a construction plan. |
| **Perimeter joint** | A movement space where tile meets walls, cabinets, columns, or other restraining surfaces. |
| **Control joint** | A planned joint in concrete that guides cracking. A tile installer must decide how the tile system handles it. |
| **Flatness** | How even the supporting surface is. A surface can be level but not flat, or flat but intentionally sloped. |
| **Level** | Exactly horizontal. Floors in wet areas may need slope and therefore are not level everywhere. |
| **Plumb** | Exactly upright. |
| **Square** | Meeting at a true right angle. Rooms and walls should not be assumed perfectly square. |
| **Slope / pitch** | A planned rise or fall over distance, such as a shower floor sloping toward a drain. |
| **Warpage** | A bow or curve within a tile. Long fired tiles may have some allowed warpage. |
| **Lippage** | A height difference between the edges of neighboring tiles. Side lighting can make it more noticeable. |
| **Shade variation** | Intended or unintended color and marking differences from tile to tile. Pieces may need to be mixed from several boxes for a natural spread. |
| **DCOF / slip-resistance rating** | A measured clue about how slippery a tile surface may be under stated test conditions. The product's intended use and current requirements still need checking. |
| **Waste / overage** | Extra material allowed for cuts, breakage, pattern needs, sorting, and future repairs. It should be calculated for the real layout, not guessed from the picture. |

## What the agent must ask when a term is unclear

- If Chrissy says **staggered**, ask for the offset: one-half, one-third, one-quarter, or random.
- If Chrissy says **vertical**, ask whether she wants vertical stack or vertical running bond.
- If Chrissy says **straight**, ask whether she means a straight grid and which way the long side points.
- If Chrissy says **centered**, ask whether a tile or a grout joint should land on the center line.
- If Chrissy names a maker's pattern, use the maker's diagram rather than assuming the repeat.
- If a floor plan is the only reference, ask for wall height and camera direction before making a room view.
